# Skyntists

Repositorio del hack de astronomía **Astro Hack**.

## Descripción

Este proyecto reúne notebooks de Jupyter y código en Python para explorar, analizar y visualizar datos relacionados con la astronomía.

## Tecnologías

- Jupyter Notebook
- Python

## Estructura

Los experimentos, análisis y visualizaciones principales se encuentran en los notebooks del repositorio.

## Uso

1. Clona el repositorio.
2. Abre los archivos `.ipynb` con Jupyter Notebook, JupyterLab o Google Colab.
3. Ejecuta las celdas en orden para reproducir los análisis.

## Estado del proyecto

Proyecto desarrollado como parte de un hack de astronomía.
